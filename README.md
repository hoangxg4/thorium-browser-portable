# Thorium Portable

Thorium Browser Portable - Chromium-based browser optimized with AVX2 by [Alex313031](https://github.com/Alex313031/Thorium-Win), packaged as a portable version with Chrome++ for local data storage.

### Features
- Thorium Portable with all data stored locally, no installation required
- Chrome++ integration for portable data directory and cache
- AVX2-optimized build for better performance on modern CPUs
- Widevine CDM included for DRM content
- Auto-update script to fetch latest Thorium releases

### Files
- `chrome++.ini` — Chrome++ configuration for portable mode
- `default-apps-multi-profile.bat` — Set Thorium as default browser
- `update.bat` — Auto-update to the latest Thorium release

### Usage
1. Download the latest release zip
2. Extract to any folder
3. Run `thorium.exe` to start
